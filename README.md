
# Glorygold.id Website

A web-based gold and silver trading platform built to showcase precious metal products, provide informational articles, and connect potential customers directly with sellers.

## Overview

Glorygold.id is a website developed to help visitors explore gold and silver product catalogs, access informational content, and communicate directly with sellers through WhatsApp.

## Key Features

- **Gold & Silver Product Catalog** – Displays gold and silver product collections.
- **WhatsApp Integration** – Allows potential customers to contact sellers directly through WhatsApp.
- **Article Section** – Provides informational articles and content for website visitors.
- **Responsive Design** – Provides a responsive interface across different screen sizes.

## Tech Stack

- **Backend:** PHP, Laravel 8
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
